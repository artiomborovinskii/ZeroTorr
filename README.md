# ZeroTorr 🚀

**ZeroTorr** — это экстремально оптимизированный, написанный с нуля на чистом **Rust** аналог **TorrServer** (API MatriX.111).
Создан специально для работы на слабых IoT-устройствах (Яндекс.Станции, ТВ-приставки, старые роутеры), где каждый мегабайт ОЗУ на счету.

| Характеристика | TorrServer (Go) | ZeroTorr (Rust) |
|---|---|---|
| Размер бинарника (arm64) | ~35 МБ | **~3.2 МБ** (нативный статический `musl`) |
| Потребление RAM в простое | 50–100 МБ | **< 5 МБ** |
| Потребление RAM при стриме 4K | Улетает за 150 МБ | **Строгий кэш (16–24 МБ)** |
| Технологии сети | Горутины (Go) | **Tokio Async + Zero-Copy** |

## 🔥 Главные киллер-фичи
1. **Zero-Copy стриминг в RAM:** Отдача кусков торрента в сеть происходит прямыми срезами памяти (`bytes::Bytes`). Ноль копирований между буферами.
2. **Аппаратное ускорение:** Доступны сборки, скомпилированные с учетом микроархитектуры (`Cortex-A53`) с задействованием инструкций `+crypto, +crc, +sha1/sha2`. Хеширование кусков не грузит процессор.
3. **Кэш Drop-Behind:** Память позади курсора воспроизведения немедленно освобождается. Вы никогда не поймаете `OOM-Killer`.
4. **API Совместимость 100%:** Поддерживает Lampa, TorrServe Client, Num и все приложения, работающие с API MatriX.111 (включая `/download/{size}` для Speedtest).

## 📥 Установка и запуск

Скачайте готовый бинарник из раздела **[Releases](../../releases)**.
Там автоматически собираются версии для `amd64`, `arm64` (Generic) и специальная аппаратная сборка `arm64-cortex-a53`.

Для слабых устройств с ОЗУ < 512 МБ (Smart Speakers) используйте флаг `--low-memory`:
```bash
./zerotorr --low-memory -p 8090 -d ./data
```
*Флаг жестко ограничивает пул потоков (2 воркера), зажимает сокетные буферы ядра до 64КБ и ограничивает размер чанков HTTP, спасая ядро Linux от нехватки памяти.*

## 🛠 Технологии
- **librqbit** — сверхбыстрый движок BitTorrent.
- **Axum / Tokio** — асинхронный HTTP-сервер.
- **Musl (mallocng)** — идеальный минималистичный аллокатор памяти, не страдающий от прожорливости `jemalloc`.
